# Portfolio site

Astro と TypeScript、Tailwind CSS を使用したポートフォリオサイトです。

## Commands

```sh
npm install       # 依存関係をインストール
npm run dev       # 開発サーバーを起動
npm run check     # Astro / TypeScript のチェック
npm run build     # 本番ビルド
npm run preview   # 本番ビルドをプレビュー
```

## Current phase

Phase 1では、Astroプロジェクトの初期設定とTailwind CSSの導入のみを行っています。
コンテンツコレクション、ページルーティング、プロフィールや作品データはPhase 2以降で追加します。
